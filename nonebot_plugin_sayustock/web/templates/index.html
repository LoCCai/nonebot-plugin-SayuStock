接入说明
NoneBot2 / QWeb

            

              
Bot 侧：OneBot v11、OneBot v12、QQ 官方机器人共用同一套命令。

              
PicMenu Next：插件元数据已包含 menu_data 三级菜单，帮助页会自动收录。

              
MoEllmChats：检测到插件后自动注册 sayustock_* ToolSpec。

              
QWeb：页面与 API 均以 /sayustock 为基座，可被 QWeb 管理台 iframe 嵌入；
              鉴权支持 Bearer token、X-QWeb-Admin 与 X-QWeb-User。

              
HTML 渲染：图表/报告是可独立打开的 HTML；PNG 需要 htmlrender + Playwright。
